# Legal Disclaimer & Authorised Use Policy

## What This Tool Is

**Ransomware Defense** is a defensive security toolkit designed to:

- Intercept encryption keys generated by ransomware **before** they are
  exfiltrated, enabling recovery of affected files.
- Monitor systems for anomalous encryption activity consistent with ransomware.
- Provide a controlled lab environment for security practitioners to study
  ransomware behaviour and practise incident response.

The toolkit was built by reverse-engineering six ransomware samples.  It
contains no ransomware payload, does not encrypt files, and does not
exfiltrate data outside a user-configured CISO endpoint.

## Capability Disclosure

This toolkit includes components that:

- **Sniff network packets** — requires elevated/root privilege and libpcap/Npcap.
- **Read process memory** — requires elevated/root privilege.
- **Hook encryption libraries** — via Frida dynamic instrumentation.
- **Load kernel modules / drivers** — Linux `.ko`, macOS kext (legacy), Windows `.sys`.

These capabilities are implemented for defensive purposes only.  The tool
is configured to send intercepted keys to a single CISO endpoint specified
in `config/config.yaml`.  It has no remote-control, persistence, or
lateral-movement functionality.
